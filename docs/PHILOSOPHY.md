# Signal Discipline

The image is already loud, so the interface stays quiet: hairlines, thin mono type and small systematic marks, placed like readings on an instrument. Every element sits on one left axis with room around it.

Color is rationed. One accent carries identity and a second, cooler one supports it. Everything else recedes into the dark. Scale sets the hierarchy: one large pixel wordmark as the anchor, one display phrase as the voice, and everything else small.

An edge ruler suggests the scene has been measured. Text is sparse and never repeated; each phrase appears once, and its position carries the rest of the meaning. Nothing overlaps and nothing crowds the subject.
